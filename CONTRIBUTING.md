# Contributing
Open a focused issue describing a user problem. Work on a feature branch, add regression coverage for changed behavior, run `python -m unittest discover -s tests -v`, and open a pull request with validation evidence. Never commit credentials, real incident logs, or employer material.

## Provenance
Personal learning project for Husnain Waleed, developed with AI assistance. Scenarios and fixtures are synthetic. It is not an employer deployment or evidence of production experience. Third-party tools retain their own licenses.
